# RBH Corrective Action UX update — Evidence before Submit

Updated October 5, 2026.

In Corrective Actions > Complete Work, the Submit for verification / Resubmit for verification button now appears after the evidence section instead of directly under the completion notes.

The visible task order is now:
1. Describe what was completed.
2. Review or add supporting evidence.
3. Submit the action for verification.

Evidence remains optional unless the company requires it. No Supabase schema, workflow status, permission, notification, or storage behavior was changed.
